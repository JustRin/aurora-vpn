Aurora VPN
Открытый клиент для панелей 3x-ui: VLESS и REALITY, режим TUN,
раздельное туннелирование и маршрутизация по правилам.
Open-source VPN client for 3x-ui / VLESS panels, powered by sing-box. MIT license.
Скачать Windows Android Linux macOS
Все сборки — на странице релизов, там же контрольные суммы. Windows после установки обновляется сам.

Протоколы

VLESS (включая REALITY и VLESS Encryption), VMess, Trojan, Shadowsocks, Hysteria2, TUIC. Импорт ссылок и подписок 3x-ui — с остатком тарифа прямо на главном экране.

Режим TUN

Виртуальный адаптер перехватывает трафик всей системы. На Windows — Wintun, на Android — VpnService с sing-box внутри процесса, как в Hiddify и NekoBox.

Раздельный туннель

«Только выбранные через VPN» или «выбранные мимо VPN» — по приложениям, с дублированием правил в DNS, чтобы запросы имён не утекали мимо маршрута.

Маршрутизация

Гео-наборы RU/CN, блокировка рекламы, свои списки доменов и подсетей. Наборы кэшируются локально — туннель поднимается даже там, где GitHub недоступен.

Два движка

sing-box как основной; узлы с VLESS Encryption и XHTTP прозрачно уходят через Xray-core. Выбор автоматический, задержки меряются одинаково.

Интерфейс

Живой журнал ядра, замер задержек, переключение Rule / Global / Direct без перезапуска, шесть тем оформления и режим «как в системе».
